# Medical-AI 云上部署手册（V4 · 香港免备案版）

> 给非工程师看的从零到上线手册。跟着步骤敲命令就行，所有"看起来吓人"的命令都在下面有粘贴版本。

- 一个管理员后台 `/admin` 给你写论文时下载数据
- 自动每日数据库备份
- 全部加密（HTTPS）

**总成本约 24 元/月，按月续费，跑完一键销毁不再收费。**

## 阶段 2：登录服务器（5 分钟）

### 2.1 Windows：用 PowerShell

打开 PowerShell（开始菜单搜 powershell），粘贴：
```
ssh root@43.155.12.34
```
（把 IP 换成你的）

第一次会问 `Are you sure you want to continue connecting (yes/no)?` —— 输 `yes` 回车。

然后输密码（看不见输入痕迹是正常的，照样敲完按回车）。

看到 `root@VM-xx:~#` 提示符 = **登录成功**。

### 2.2 Mac：终端

完全一样的 `ssh root@<IP>`。

## 阶段 3：一键部署（5-10 分钟）

直接复制粘贴以下 4 条命令，**一次跑完**：

```bash
apt update && apt install -y git
git clone https://github.com/lordrance/Medical-AI.git
cd Medical-AI
git checkout V4
bash deploy/setup.sh
```

脚本会**交互式问你 3 个问题**，按提示回车就行：

1. **用 nip.io 域名？** → 直接回车（用自动检测的 IP 域名）
2. **管理员后台密码？** → 直接回车（用脚本自动生成的强随机密码，会显示在最后）
3. **DeepSeek API key？** → 直接回车（V4 不用 LLM，跳过）

然后等 3-5 分钟，**最后会看到**：

```
========================================
  部署完成！
========================================

🩺  受试者访问网址（发给医生）：
    https://43-155-12-34.nip.io/

🔐  管理员后台（你写论文取数据用）：
    https://43-155-12-34.nip.io/admin
    Token: a1b2c3d4e5f6...
```

**重点**：把 Token 复制到一个安全的地方（你的密码管理器 / 微信收藏 / 邮件给自己）。

## 阶段 6：取数据（论文阶段，10 分钟）

打开 `https://43-155-12-34.nip.io/admin`，输 Token 登录。

页面有 3 个下载按钮：

| 按钮 | 你拿到 |
|---|---|
| **下载数据 ZIP** | 所有表的 CSV（参与者、答题、行为日志、问卷） |
| **下载录音 ZIP** | 所有医生的语音回答 + index.csv |
| **下载整库 SQL** | 数据库的完整 pg_dump，最稳的归档格式 |

下载到你自己电脑后，**这就是你写论文用的全部数据**。

## 阶段 7：研究结束清理（5 分钟，**很重要**）

确认数据已经全部下载到本地后：

### 7.1 关闭并清空服务器数据

ssh 登回服务器：
```bash
cd Medical-AI
docker compose -f docker-compose.prod.yml down -v
```
`-v` 是关键，它会**销毁数据库 volume**，彻底清空云上数据。

### 7.2 销毁服务器实例

打开腾讯云控制台 → 轻量应用服务器 → 你那台实例 → 点「**销毁**」（不是关机，是销毁）。

确认销毁后**不会再产生任何费用**。下个月不需要续费。

## 常见问题

### Q: 我访问网址显示"证书错误"

第一次部署后 30-60 秒内是正常的（Caddy 在申请证书）。等 1 分钟刷新即可。

如果 5 分钟后还报错，登服务器看日志：
```bash
docker compose -f docker-compose.prod.yml logs caddy
```

通常是端口 80/443 没放开。腾讯云控制台 → 防火墙 → 加 80 + 443 入站规则。

### Q: 医生说访问慢

香港节点国内延迟通常 50-100ms，影响很小。如果有医生反馈持续慢：
- 看是否是高峰时段
- 看医生是不是在某个特殊网络（公司内网代理）

### Q: 我想加更多医生进度怎么办

没什么特殊要做的，**直接发链接给新医生**就行，云服务器自动接待。

### Q: 服务器要重启吗？

不用。腾讯云会自动维护硬件层。即使重启，`restart: always` 配置保证 Docker 容器自己起来。

### Q: 如果我中途想升级代码

```bash
ssh root@<IP>
cd Medical-AI
git pull
docker compose -f docker-compose.prod.yml up -d --build
```
注意这会丢失正在做测试的医生的进度（30-60 秒服务中断）。**避免在研究高峰时段做**。

### Q: 我要立刻在论文准备阶段全量备份一次

```bash
ssh root@<IP>
cd Medical-AI
bash deploy/backup.sh
```
然后在你自己电脑上：
```bash
scp root@<IP>:~/Medical-AI/backups/medical-ai-*.tar.gz .
```
拉到本地。

## 三条最重要的"千万别做"

1. **千万别把 .env 文件 commit 到 GitHub** —— 里面有数据库密码和 ADMIN_TOKEN。`.gitignore` 已经排除了，但你要是手动加进去就糟了。
2. **千万别在 `docker compose down -v` 之前下完数据** —— `-v` 会清掉数据库。
3. **千万别把管理员后台网址 + Token 一起发给医生** —— 医生应该只拿到 `/` 主页，不知道 `/admin` 的存在。
